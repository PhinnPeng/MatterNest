## 候选 1 · 四条「否定式」断言无法自证还会咬人（✅ 已落地）

**为什么这是本仓最该修的一类**：它命中的是**门禁自身的完整性**，而本仓的立身之本
就是「门禁是机械的」。

审计 8 条源码断言，四条挡不住「正则腐掉」：

| 断言 | 本次之前 | 现在 |
|---|---|---|
| `assertNoSubtitleSlots` | ❌ 连 canary 都没有 | ✅ `SUBTITLE_SELF_CHECK` |
| `assertRichTextWhitelist` | ❌ 连 canary 都没有 | ✅ `RICH_TEXT_SELF_CHECK` |
| `business-day` | ❌ canary 只数**文件** | ✅ `SELF_CHECK` |
| `judge-portability` ③ | ⚠ canary 只数文件（≥50） | ✅ `MACHINE_PATH_SELF_CHECK` |

（另三条本来就挡得住：`smoke-hygiene` 的 `scanned` 数的是**命中**语句、
`secret-literals` 用「逐把密钥各须出现」、`antd-deprecated` 有 `SELF_CHECK`。）

**修法**：每条加一段「必然命中的正样本」自检 —— 形状抄 `antd-deprecated.mjs`。
⚠ **不能把计数挪回命中数**：那会制造假红（干净仓库命中数天然为 0）。

**反向红**：逐条把正则换成 `NEVER_MATCHES_XYZ`，`check.mjs` 各自退出 1 并报出
「匹配式连自检样本都匹配不上」；还原后复绿。四条都实测过。

## 候选 2 · `git checkout <file>` 会静默毁掉别条线的在制品（✅ 已落地：spec）

**实测事故**：做反向红时用 `git checkout src/app/lib/server/services/reports.ts` 还原注入，
**连同品牌线那句注释删除一起抹掉了**。

最危险的不是丢东西，是**丢得看不见**：当场发现**自己的**改动没了并重新应用，
**没发现别人的也没了** —— 约 40 分钟后才察觉。找回靠
`git fsck --no-reflogs --unreachable`（103 个不可达 blob 里认出原版本）；
**`git gc` 一跑就真没了**。

**根因不是纪律缺失**：这条规矩仓里早有，写在 5 个 `revred-*.mjs` 的头注里 ——
但那次是**手搓的临时注入脚本**，不读那些头注。

⇒ 写进 `.trellis/spec/backend/quality-guidelines.md`，让**临时脚本的作者**也读到。

## 候选 3 · 别线的未跟踪文件挡住**全仓**提交（✅ 已落地）

⇒ `.prettierignore` 加 `DESIGN.md` / `PRODUCT.md`，照 `.impeccable/` 与 `docs/` 的先例

但"卡住所有人"不能是默认状态**。

## 候选 4 · 搜索工具会静默骗人（✅ 已落地：spec）

`grep -rn '\d{1,19}' src/` 得到 0 命中，据此回报「**零基线**，只有 `http.ts` 一处」——
实际 4 处。本机 `grep` 是 **ugrep**，`\d` 在裸形态下静默不匹配：

```
① 裸 \d{1,19}      → 0 命中     ← 静默失配
② -F d{1,19}       → 1
③ -E '\d{1,19}'    → 2  ← 可用
④ -P '\d{1,19}'    → 2
```

**代价比门禁那次更大**：我把这个假前提**写进了子代理的简报**，而子代理用 `-F` 反证了我。
假前提会顺着简报流进下游，让子代理要么白干、要么花大量 token 反过来推翻你。

⇒ 写进 spec：「报『仓里没有 X』之前，必须用**同一取法**搜一个必然存在的正样本」。
