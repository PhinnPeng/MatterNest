## A. 基线正文

### 一、产品概述

#### 1.1 产品定位
MatterNest 是面向企业内部法务部门的案件与风险事项管理平台，以台账式管理为起点，覆盖风险事项、案件、案例、当事人等核心对象，实现"风险 → 案件 → 结案 → 归档"的全生命周期管理。

#### 1.2 核心设计理念
- 状态与节点统一：状态是宏观阶段（待受理/进行中/已结案/已归档），节点是阶段内的里程碑。
- 软约束生命周期：允许自由跳转，偏离推荐路径时二次确认并留痕。
- 归档即状态：归档动作 = 将状态变更为"已归档"，立即执行。
- 自动化规则可控：动作一对一、禁止状态变更动作、禁止多规则触发节点、规则不级联。
- 关注驱动提醒：关注人 + 收藏按钮 + 自定义提醒 + 案程节点提醒。

#### 1.3 目标用户

| 角色 | 职责 |
|---|---|
| 管理员 | 全部数据与配置 |
| 法务总监 | 全部可见，操作自己参与的 |
| 普通法务 | 自己参与的案件/事项 |
| 外部/访客 | 只读 |

#### 3.2 状态设计（与案件共用）
固定 4 个状态，不可增删改：

| 状态 | 含义 | 是否归档状态 |
|---|---|---|
| 待受理 | 新录入，尚未正式启动 | 否 |
| 进行中 | 正在处置 | 否 |
| 已结案 | 已化解 | 否 |
| 已归档 | 封存 | 是 |

允许自由跳转，偏离推荐路径时二次确认 + 填写变更原因。状态变更写入活动日志。

#### 3.3 节点设计
默认 3 个节点：风险评估 / 处置执行 / 化解确认。支持用户增删改。节点字段：名称、时间点（仅时间点，简化）、提醒配置、负责人、状态（未开始/进行中/已完成/已取消）、备注。

#### 3.4 转案件（1:N）
- 入口：风险事项详情页 → "转案件"。
- 自动带入：当事人、涉及金额、描述、附件、负责人、关注人。
- 支持转单个或多个案件，每个案件独立补录字段。
- 提交后：
  - 生成 N 个案件，案件详情页显示"来源：风险事项 FX-xxx"。
  - 风险事项状态 → 已转案件（自动触发归档）。
  - 风险事项详情页列出所有关联案件，可跳转。
- 已转案件的风险事项不可再次转案件。

#### 3.5 其他操作
- 增删改查、筛选、搜索、批量操作。
- 提醒：创建时按提醒配置自动提醒负责人 + 关注人；支持自定义提醒事项。
- 归档：归档后默认列表隐藏，可切"已归档"视图；管理员可撤销。
- 关注/收藏、评论 @、标签、风险等级。

#### 4.2 状态与归档
- 状态：待受理 → 进行中 → 已结案 → 已归档（推荐路径）。
- 允许自由跳转，偏离时二次确认 + 填原因。
- 归档 = 状态变更为"已归档"，立即执行。
- 归档后：列表默认隐藏、核心字段只读、评论/附件仍可新增。
- 从"已归档"切回其他状态时，自动撤销归档。

#### 4.3 案程节点

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| 名称 | 文本 | 是 | |
| 节点类型 | 单选 | 是 | 配置读取 |
| 时间类型 | 单选 | 是 | 时间点 / 时间段 |
| 开始时间 | 日期时间 | 是 | |
| 结束时间 | 日期时间 | 时间段时必填 | |
| 提醒配置 | JSON | 否 | 提前天数，如 [7,3,1] |
| 负责人 | 人员 | 否 | |
| 状态 | 单选 | 是 | 未开始/进行中/已完成/已取消 |
| 备注 | 文本 | 否 | |

案件节点完整支持时间点/时间段。状态变更为"进行中"时，按模板自动创建节点（立案/举证/开庭/判决）。支持手动增删改。

#### 4.4 案件进展
字段：进展日期、进展类型（配置）、进展内容、记录人、附件。展示：时间线倒序。

#### 4.5 活动日志
自动记录：操作人、时间、操作类型、字段级 diff。不可编辑。

#### 4.6 费用（仅支出）
字段：费用项目、金额、发生日期、状态、备注、附件。支持案件内汇总、按项目分组。

#### 4.7 评论与回复
一级评论 + 二级回复。支持 @提及，被 @ 的人收到通知。归档后仍可新增评论。评论不可编辑，本人/管理员可删除。

#### 4.8 标签 / 风险等级
标签：多选，配置读取，带颜色，可筛选。风险等级：单选，配置读取，带颜色，可筛选。

#### 4.9 生成案例（1:1）
前置条件：案件状态为 已结案 或 已归档。一个案件仅能生成一个案例，生成后按钮置灰。案件详情页显示"已生成案例"，可跳转。

### 七、模块五：配置

- **7.1 通知配置**：渠道（站内/邮件/短信/微信）、模板、触发条件、频率。
- **7.2 提醒配置**：默认提前天数、多级提醒、重复提醒、超期升级、提醒方式、自动提醒规则。
- **7.3 存储配置**：存储类型、路径规则、大小限制、文件类型白名单、在线预览开关。
- **7.4 智能体配置**：模型选择、API Key、API 地址、启用场景、提示词模板、调用限额。
- **7.5 MCP 服务 + 授权页**：服务配置（名称、地址、认证方式、可用工具、启用状态）；授权页（列出服务、授权状态、授权/撤销、有效期、操作日志）。
- **7.6 费用项目配置**：名称、编码、是否启用、排序（仅支出）。
- **7.7 风险等级配置**：名称、颜色、排序、启用。
- **7.8 标签配置**：名称、颜色、分组、启用。
- **7.9 案件/风险状态配置**：固定 4 个：待受理、进行中、已结案、已归档。可配置颜色、排序、默认节点模板、是否归档状态（仅"已归档"为 true）。
- **7.10 节点类型配置**：名称、适用类型（案件/风险/通用）、时间类型、默认提醒提前量、排序、启用。

### 九、关注 / 收藏 / 提醒机制

- **9.1 关注人**：创建时可直接添加，详情页可增删。任何更新（状态、进展、费用、节点、评论等）自动通知关注人。
- **9.2 关注列表 + 收藏按钮**：收藏按钮在详情页右上角 ⭐，点击加入关注。关注列表：个人中心 → "我的关注"，显示未读更新数。
- **9.3 自定义提醒**：字段：标题、提醒时间、提醒人、提醒方式、重复、备注。
- **9.4 案程节点提醒**：节点自带提醒配置，按提前量触发。
- **9.5 自动提醒规则汇总**

| 触发条件 | 提醒对象 |
|---|---|
| 案件/事项有更新 | 关注人 |
| 案程节点临近 | 负责人 + 关注人 |
| 自定义提醒到期 | 指定提醒人 |
| 长期未更新（30天） | 负责人 |
| 费用待支付超期 | 负责人 |

### 十三、自动化规则引擎详细设计

#### 13.1 规则模型
```text
WHEN [触发条件] AND [附加条件] THEN [执行动作]
```

#### 13.2 触发条件
状态变更、时间触发、事件触发、组合条件。

#### 13.3 动作白名单

| 动作 | 允许 | 唯一性 |
|---|---|---|
| 归档 | ✅ | 全局唯一 |
| 发送通知 | ✅ | 全局唯一 |
| 创建节点 | ✅ | 全局唯一 |
| 分配人员 | ✅ | 全局唯一 |
| 更新字段（非状态） | ✅ | 全局唯一 |
| 变更状态 | ❌ | 禁止 |

#### 13.4 约束
动作一对一：每个动作只能被一条规则触发。禁止"变更状态"作为动作。禁止多条规则触发"更新节点"。规则不级联：不响应其他规则的执行结果。

#### 13.5 预置规则

| # | 触发条件 | 动作 | 优先级 |
|---|---|---|---|
| 1 | 状态变更为"已结案" | 归档（立即） | 10 |
| 2 | 状态变更为"已结案" | 发送通知→关注人 | 20 |
| 3 | 状态变更为"进行中" | 创建节点（按模板） | 10 |

| 5 | 节点开始前3天 | 发送通知→负责人+关注人 | 10 |
| 6 | 节点结束前3天 | 发送通知→负责人+关注人 | 20 |
| 7 | 风险状态变为"已转案件" | 归档（立即） | 10 |

#### 13.6 冲突检测
配置时检测动作占用，提示。运行时再次校验，冲突则跳过并告警。

### 十四、页面原型描述（摘要）
- **14.1 通用列表页**：顶部搜索/筛选/新建，表格列显示编号、名称、状态、等级、负责人、更新时间，支持批量操作和导出。
