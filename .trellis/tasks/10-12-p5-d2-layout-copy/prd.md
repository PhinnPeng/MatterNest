# P5-D2 一：布局改判 + 文案改名（界面层）

## Goal

把 IQ-19 的 D2 形态落到真代码：事项详情页从 IQ-17 的「单栏流式 + 等高节点栏」改成 **左内容 + 右评论栏**。布局以分支 `prototype/p5-p6-2026-10-11` 的**变体 D2**（提交 `5513abc`）为准，不再自由发挥。

Paca：**MATT-55**（父卡 MATT-54）。

## Requirements

**R1 页头并入左列**（不是整幅）：编号与标题同行、动作在内容区最右；描述与处置措施在标题下方成为两个字段块；静态字段收成**一行** `dt/dd`；当事人/参与人/附件/登记信息进默认收起的折叠区。

**R2 右栏只剩评论**：输入框钉在底部、列表自带滚动、**栏底恒在折线以上 20px**；`已转案件` 不再占右栏（收进 R1 的字段行，hover 出详情）。

**R3 页签减到两枚**：事项节点 / 活动日志。原「详细信息」按 R1 回送到描述下方。

**R4 加节点按钮**移进「事项节点」面板内（不在页签栏）。

**R5 两列等高**：左列 `min-height` = 右栏高、顶边对齐。

**R6 文案改名**：界面 13 处「风险事项」→「事项」（登录页与 `layout.tsx` 站点描述**两处保留**）；「变更处理人」→「变更经办人」；「活动流」→「活动日志」（案件侧页签「活动」同步改）；「风险描述」→「描述」；「软删」→「删除」（确认文案保留"库里仍保留、无回收站"）。

## Acceptance Criteria

- [ ] 1366 下容器 1106 = 左列 750 + 16 + 右栏 340；两列顶边同 y、等高
- [ ] 右栏底边距折线 20px（不是 0、也不是落在折线以下）
- [ ] 页签恰好两枚；「手动添加节点」只出现在节点面板内
- [ ] 元素级横向溢出 0（逐元素核，不看整页 `scrollWidth`）
- [ ] 归档态：无评论输入框、无关注菜单、加节点按钮消失
- [ ] 三处空态（节点 / 评论）都有交代；已转案件为 0 时字段行显示 `0 件` 且 hover 有说明
- [ ] 改名逐条核对：13 处「风险事项」清零（登录页与站点描述两处除外）、四项术语各 0 处旧词
- [ ] `pnpm verify` 五道 + `pnpm build` 绿；`agent-work/smoke-demo.mjs` 真 HTTP 断言全绿
- [ ] 两条既有失败不许扩大：`enum-check` 已由别票修好（120 条全绿），完成后仍是全绿

## Out of Scope

- 关注组（MATT-56）、描述富文本（MATT-57）——它们各自一票。
- `PageHeader` 的签名（`title/code/status/flags/actions` 保持不变）。
- 案件侧任何布局改动（只同步「活动」页签的文案）。
